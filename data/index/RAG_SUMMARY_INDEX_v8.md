# 三、v8.0 工程組件 spec

## BrowserNode — 瀏覽器作為外部感官
`BROWSER_NODE.md`

v8.0 知識層（Layer 3 of 7）嘅唯一外部數據入口。四個核心組件：web_search（接 DuckDuckGo + Brave + Wikipedia 嘅自 host 組合）、fetch_url（拉取單一 URL 內容並計算 content_hash）、parse_content（HTML → main_text + metadata）、cache（避免重複 fetch + 維持 audit 可重複性）。所有 fetch 結果強制經 SourceCoordinateRegistry 八律審計，UNVERIFIED 來源禁止入分析 pipeline。連接 CivilizationalClock：window_urgency 越接近 1（**2035** 反格式化窗口關閉，v8.30 canonical；舊 2038 已 superseded），地理律權重提升，搜尋偏向接近代價承擔者嘅來源。設計原則：搜尋工具自身有座標，必須申報——商業 API（Tavily/Serper）座標未申報，違反協議原則，故 v8.0 建議自 host。

## SourceCoordinateRegistry — 來源座標審計層
`SOURCE_COORDINATE_REGISTRY.md`

v8.0 知識層審計子層（Layer 3.5 of 7）。將 SCR_TEMPLATE 嘅八律真實性過濾擴展到任何 web 來源——對象從歷史人物 profile（手動，小時計）擴展到單次 web fetch（自動，秒計）。四級評級：VERIFIED（一手 + 八律全通過）/ PROBABLE（六律以上，二手但內部一致）/ INFERRED（四律以上，推論性使用）/ UNVERIFIED（少於四律，禁止用於分析）。Source Schema 包含 publisher coordinate、author coordinate、八律分數、coordinate_position（地理 + 意識形態 + 利益）、cost_disclosure、content_hash 不可變引用。Composer 強制嘅 audit summary section：所有引用必須附評級 + publisher + content_hash + fetched_at。核心原則：唔評估「真假」，評估「座標位置」——聲稱中性嘅來源 = UNVERIFIED（座標被隱藏），明確政治立場嘅來源 = 可達 VERIFIED（座標已申報）。

## 兩個組件嘅關係

BrowserNode 同 SourceCoordinateRegistry 永遠成對運作。BrowserNode 唔做 audit 嘅 fetch = 退化到普通 web search。Registry 冇 BrowserNode 提供嘅資料 = 冇對象可 audit。兩個獨立 spec 文件嘅理由：BrowserNode 嘅 spec 屬於「點拉資料」，Registry 嘅 spec 屬於「拉到之後點審計」——分開兩個關注面，但 Phase 2 同步實作。

# 四、Framing Patterns Toolkit（v8.1 新增）

## 用途

主權新聞過濾器（／news 子系統）嘅 hidden coordinate detection 擴展。每個 pattern 係 multi-律 intersection（八律湧現節點），唔係 individual 媒體選擇 — 結構性 framing-acceptance enabling structures。被接受嘅 framing 唔淨係描述事件，係 enable 下一階段升級。識別 chain position 比分析 individual claim 更核心。

來源：2026-05-07 /uruk-news 30 個月連續窗口分析（2024-01-01 → 2026-05-07）cumulative emergence。配對檔案：CAUSAL_RECORD_2024-01_to_2024-08.md + CAUSAL_RECORD_2024-09_to_2025-04.md + CAUSAL_RECORD_2025-05_to_2026-05.md。

## Pattern 1 — Surgical / Precision Normalization
`5 個 framing patterns toolkit § 1`

通過「surgical」「precision」「targeted」一個詞涵蓋從 precision 到 indiscriminate 嘅整個 spectrum。將 normative 限制（「precision = OK」）變成 enabling permission（「我哋 precision，所以 OK」）。多律 intersection：LAW 5（Source / 來源）× LAW 8（Religion / Mythologization）。30 個月窗口出現 13 次。主要 case：傳呼機 supply chain 攻擊（2024-09）、Nasrallah 80 噸炸彈（2024-09）、黎巴嫩 daily strikes（2024—2026）、Khamenei 暗殺（2026-02）。

## Pattern 2 — Mandate Inflation
`5 個 framing patterns toolkit § 2`

邊際勝利被 framing inflate 為「歷史性 mandate」，授權膨脹 enable 嘅 institutional damage 唔可同時間 reverse。多律 intersection：LAW 1（Art / 表達一致性）× LAW 6（Philosophy / 內部一致性）。30 個月窗口出現 9 次。主要 case：特朗普 2024 普選票 ~230 萬 margin → 142 行政令 100 日 → USAID 解散 / Liberation Day / 白宮爭吵。一年後民調回到 record-low，但 institutional damage 已唔可逆。

## Pattern 3 — Telegraphic Strike Normalization
`5 個 framing patterns toolkit § 3`

通過提前通知 + 限定規模嘅打擊作為 signaling，但 binary win/lose framing 將 communicative 性質 collapse → 升級無 off-ramp。多律 intersection：LAW 7（Geography）× LAW 3（Physics / Cost）× LAW 6（Philosophy / 公設選擇）。30 個月窗口出現 5 次（新興）。主要 case：真實諾言 I（2024-04）、II（2024-10）、III（2025-06）、IV（2026-02）。每次都被 framing 為「success」或「flop」，掩蓋實際 communication 嘗試 — 升級因此無 off-ramp。

## Pattern 4 — Carcass Narrative
`5 個 framing patterns toolkit § 4`

「殺領袖 = 結束組織」嘅儀式化敘事。每次接班即 falsifying evidence，但 narrative 從未 retract。多律 intersection：LAW 2（Psychology / 行為對齊）× LAW 5（Source）× LAW 8（Mythologization）。30 個月窗口出現 6 次（新興）。7 個 case 鏈：Mousavi → Zahedi → Haniyeh → Shukr → Nasrallah → Yahya Sinwar → Khamenei。每個接班（Mojtaba Khamenei、Mohammed Sinwar、Naim Qassem）都 invalidate「decapitation = end」假設，但 narrative 持續被應用。

## Pattern 5 — Generational Identity Collapse
`5 個 framing patterns toolkit § 5`

將結構性問題 reframe 為 generational identity（age cohort），令深層結構問題（governance erosion、經濟不平等、capability shift）折疊為個人世代敘事。多律 intersection：LAW 6（Philosophy / 公設選擇）× LAW 8（Mythologization）。30 個月窗口出現 4 次（新興）。主要 case：Bangladesh「Gen Z 革命」(2024-08，將 16 年 authoritarian drift 折疊為世代衝突)、Trump base「老人 vs 新世代」、AI「成功者世代」。「Gen Z」標籤令 case 似可複製，但結構性 prerequisites 唔自動存在。

## 跨 Pattern 結構

5 個 pattern 共享一個 meta-structure：

```
被接受嘅 framing → enable 下一階段升級嘅 conditional structure
單一 framing acceptance 嘅 cost ≠ 個別事件
而係 enabling 下一節點嘅 trajectory dependency
```

29 個月以色列升級邏輯 chain（從 2023-12-25 Razi Mousavi 暗殺到 2026-02-28 戰爭）= 三個 pattern（Surgical + Telegraphic + Carcass）共同作用嘅大規模實證 case study。每個節點都係前一節點 framing acceptance 嘅直接因果結果，冇任何節點係 isolated decision。
