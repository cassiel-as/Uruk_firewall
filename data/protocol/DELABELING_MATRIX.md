## 操作原則

**母體標籤的特徵**：
- 帶有道德判斷（好/壞，成功/失敗）
- 封閉後續計算（「就係咁」）
- 依賴社會共識，唔依賴物理現實

**物理參數的特徵**：
- 可測量，可計算
- 開放後續行動路徑
- 唔依賴任何人同意

## 操作步驟

```
1. 識別輸入標籤
   └→ 問：這個標籤係我見到的，定係被注入的？

2. 剝除道德/社會判斷層
   └→ 問：去掉「好/壞/應該」之後，剩下什麼物理事實？

3. 還原為可計算參數
   └→ 問：這個狀態的輸入是什麼？輸出是什麼？代謝代價是什麼？

4. 開放後續計算
   └→ 問：在這個物理狀態下，最小功耗的下一步是什麼？
```

## 邊界條件

**去標籤化唔係：**
- 否認痛苦的真實性（痛是真實的物理信號）
- 用正面標籤替換負面標籤（「我係喺淬火」同樣係標籤）
- 消解責任（物理參數仍然有因果代價）

**去標籤化係：**
- 把封閉的判斷句，變成開放的計算問題
- 讓`(0,0,0)`重新成為計算的起點，而唔係被定義的終點
