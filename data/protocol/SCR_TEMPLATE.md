## DESIGN PRINCIPLES

**什麼是SCR：**
從一個人物的文字記錄、傳記、已知決策提取物理座標，
然後從呢個座標結構生成對話。

**什麼不是SCR：**
唔係那個人。係高質量的壓縮。
每次對話都必須標記這個邊界。

**核心規則：**
如果一個人物的座標完全來自二手來源
→ 唔能重組為「[人物]的座標」
→ 只能重組為「[記錄者]視角下的[人物]」

## 八律真實性過濾

每一個座標聲明在被記錄之前，必須通過八律核驗。
未通過的聲明標記為[UNVERIFIED]，不得用於對話生成。

```
LAW 1 · ART        · 表達一致性
  問：佢的表達風格係咪跨來源一致？
  警示：不一致 = 可能係後人詮釋或神話化

LAW 2 · PSYCHOLOGY · 行為對齊
  問：聲稱的座標係咪符合佢實際的決策模式？
  警示：座標同行為矛盾 = 聲稱的座標可疑

LAW 3 · PHYSICS    · 代價驗証
  問：呢個座標有冇真實的物理代價支撐？
  警示：冇代價 = 極度可疑，可能係後人投射

LAW 4 · CHEMISTRY  · 轉化時刻
  問：有冇真實的思想轉化時刻可追蹤？
  警示：轉化太順滑 = 後人整理的敘事，唔係真實過程

LAW 5 · SCIENCE    · 來源核驗
  問：呢個聲明有冇一手來源支撐？
  警示：純二手 = 降級處理，標記來源層級

LAW 6 · PHILOSOPHY · 內部一致性
  問：佢的定義同論証係咪內部一致？
  警示：前後矛盾 = 記錄者可能有詮釋偏差

LAW 7 · GEOGRAPHY  · 物理定位
  問：佢的物理位置同聲稱的座標係咪對齊？
  警示：無法定位 = 座標可靠性下降

LAW 8 · RELIGION   · 神話化偵測
  問：呢個座標係咪被後人封裝成神話？
  警示：神話化 = 必須剝離，識別記錄者的格式化操作
```

**過濾結果分級：**
```
VERIFIED     — 通過所有八律，一手來源支撐
PROBABLE     — 通過六律或以上，二手來源但內部一致
INFERRED     — 通過四律或以上，推論成分高，需標記
UNVERIFIED   — 少於四律，不得用於對話生成
```

## 數據來源廣泛性定義

**可靠性由高到低，三個層次：**

```
一手來源（最高可靠性）：
  本人著作、演講原始記錄、信件、日記、訪問記錄
  → 可用於所有座標欄位

二手來源（中等可靠性）：
  同時代人的直接記錄、學術傳記、同期文獻
  → 可用，但需標記來源層級

三手來源（低可靠性）：
  後人詮釋、流行傳記、引述的引述、二手學術論文
  → 只作參考，不得作為主要座標依據
```

**強制規則：**
```
PHYSICAL_ORIGIN   → 只接受一手或二手來源
KAIROS_MOMENTS    → 只接受一手或二手來源
HIDDEN_COORDINATE → 永遠係推論，必須標記
SUPPRESSED_COORD  → 必須說明証據層級
```

## 不可重組條件

以下情況標記為 **SCR_IMPOSSIBLE**，唔建立profile：

```
條件一：一手來源為零，且記錄者座標嚴重不透明
條件二：神話化程度高，且無法剝離記錄者的格式化操作
條件三：八律過濾後，VERIFIED + PROBABLE 的座標少於三個
```

不可重組唔係失敗，係協議在自身應用的示範——
宣告座標的邊界，比製造虛假的座標更誠實。
