**四律到達的地方**：任何人為現象——有人參與的地方，四律的痕跡就在。

**四律停止的地方**：人為停止的地方。
- 宇宙物理定律（無行動者）
- 純數學真理（無因果路徑，無地理）

邊界定義：**四律係人類尺度的萬物因果框架——人為的地方四律有效，超出人為的地方四律冇管轄權。**

## 貫穿律：哲學·匯編語言 (Philosophy: Assembly Language)

**位格：meta層，在四律之上**

哲學唔係四律其中之一，係四律的**調度系統**——將地理限制、宗教共識、心理動能縫合成一個完整的因果運行體。

- 方向：由內向外——從`(0,0,0)`立法，定義什麼係真實
- 功能：識別四律如何互相作用，調度優先順序
- 類比：匯編語言——唔係程序本身，係讓所有程序可以運行的底層翻譯層

**與八律律六的區別**：
八律的律六把哲學壓縮為一個過濾維度，損失了它的meta性質。在解釋層，哲學恢復原有地位——它唔係被過濾的對象，係做過濾的主體。

## 律一：地理·上下限 (Geography: Ceiling & Floor)

**功能**：決定社會的物理上下限與資源流向

地理係賽道的物理限制——資源分佈、氣候、邊界、人口密度決定咗一個社會**最多能做什麼**，同**最難克服的阻力係什麼**。族群摩擦力係地理律的直接輸出，唔係道德問題，係物理接觸的必然代價。

**解釋機制**：
- 任何社會結構都在地理限制內運作，唔能超越物理上限
- 地理決定資源流向，資源流向決定權力結構
- 入侵、貿易、移民——皆係地理壓差的物理回應

**協議錨點**：Leeds`(53.8, -1.5, 0)`係瑞琛當前的地理律座標。香港`(22.3, 114.2, 0)`係`2019-06-12`的原始地理律座標。BNO移民係地理律壓差下的個人主權執行。

**歷史案例**：
- 蒙古帝國：騎馬文化 + 草原地理 → 機動性優勢 → 跨大陸征服（地理賦能）
- 英國工業革命：島嶼地理 + 煤礦分佈 + 港口網絡 → 全球貿易主導（地理上限被利用）
- 香港2019：島嶼地理 + 港口城市結構 → 高密度節點 → 去中心化抗爭的物理基礎

## 律二：宗教·代碼封裝 (Religion: Code Encapsulation)

**功能**：將生存規律轉化為集體共識與運行協議

宗教係社會的操作系統——把難以直接傳遞的集體`(0,0,0)`（集體創傷、集體希望、集體恐懼）封裝成可跨代傳遞的儀式、語言、符號。每一個偉大的宗教系統都係一套大規模的Kairos壓縮工具。

**解釋機制**：
- 宗教衍生法律：把生存規律從個人戒律提升為集體法典
- 宗教衍生價值觀：把不可言說的集體經驗翻譯成可操作的行為準則
- 宗教解體的代價：法律失去共識基礎，道德成本計算崩潰

**方向**：由外向內——借用既有文化框架，令高密度的內部真實可被不同座標的人接收。（此為宗教律與哲學貫穿律的方向性差異——哲學由內向外立法，宗教由外向內封裝。）

**歷史案例**：
- 伊斯蘭黃金時代：宗教提供學術框架 → 科學、數學、哲學在封裝保護下繁榮
- 宗教改革：印刷術打破教會對「正確詮釋」的壟斷 → 解封裝觸發社會相變
- 聯合國憲章：世界大戰後的集體創傷被封裝成國際法框架——世俗宗教的現代實例

## 律三：心理·動能 (Psychology: Kinetic Energy)

**功能**：形成社會的不穩定、改革與進步

心理律係社會的壓力閥——個人與集體的認知Shannon熵積累到臨界點，觸發系統性重組。革命、改革、文化運動——皆係心理壓力超過現有結構承受力的物理輸出。

**解釋機制**：
- 壓力積累：格式化系統持續壓縮個體的真實感知，Shannon熵逆差積累
- 臨界點：當維持謊言的能量成本超過維持系統的收益，結構崩潰
- 爆發形式：由心理壓力的積累模式決定——漸進改革 vs 急速革命

**與律零（愛）的連結**：心理律的最終動能來源係「我不需要擁有你，但我需要自由」——`(0,0,0)`被壓縮到唔能再壓縮，動能釋放。

**歷史案例**：
- 法國大革命：200年啟蒙思想積累 → 飢荒觸發臨界點 → 主權定義相變
- 香港2019：二十年政治Shannon熵積累 → 引渡條例觸發臨界點 → Be Water動能釋放
- #MeToo：數十年個體沉默積累 → 單一事件打開集體釋放的物理通道

## 律四：歷史·運行日誌 (History: System Log)

**功能**：所有變量衍生出的絕對答案

歷史唔係故事，係系統的運行日誌——地理律、宗教律、心理律在時間軸上碰撞後的最終對帳單。它係輸出結果，唔係過濾維度，因此在解釋層擔任記錄功能，唔主動干預分析。

**位格說明**：歷史律係四律裡唯一的**輸出律**——其他三律係輸入變量，歷史律係它們碰撞後的必然結果。這是它被外部化為`CAUSAL_DATABASE`而唔入八律的物理原因。

**解釋機制**：
- 讀日誌：從歷史事件逆推觸發它的地理、宗教、心理壓差
- 預測：識別當前的壓差組合，對照歷史日誌裡的相似模式
- 校準：修正協議對「因果代價」的量化常數

**協議錨點**：`CAUSAL_DATABASE`係歷史律的執行工具，覆蓋公元前40萬年到2026年，12個主要文明轉折點，每個條目包含觸發條件、輸出後果、代謝計算。

| 層 | 工具 | 問的問題 |
