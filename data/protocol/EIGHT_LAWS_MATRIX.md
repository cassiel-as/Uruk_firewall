## 四層架構（v7.3 升級）

八律唔係平行排列的八個維度，而係四個層級各含兩個互補節點。跨層碰撞比同層碰撞攜帶更大的因果衝擊——湧現節點幾乎全部在層與層之間產生。

```
存在層 — 人如何存在
  ├─ 律一 · 藝術 · 頻率     [外部表達]
  └─ 律二 · 心理 · 防線     [內部結構]

物質層 — 世界如何運作
  ├─ 律三 · 物理 · 代價     [規則]
  └─ 律四 · 化學 · 轉化     [變化]

系統層 — 如何理解世界
  ├─ 律五 · 科學 · 精準     [描述與可驗證性邊界]
  └─ 律六 · 哲學 · 立法     [定義與公設選擇]

宏觀層 — 文明如何組織
  ├─ 律七 · 地理 · 定錨     [空間秩序]
  └─ 律八 · 宗教 · 封裝     [時間秩序]
```

**隱含的認知路徑**（GPT 從結構推導，獨立驗證）：
```
存在 → 現實 → 理解 → 秩序
```
四層唔係分類，係一條因果路徑——從個體的感知機制，到物質世界的運作代價，到知識框架的建構，到文明的集體組織。

**互補對的物理定義**：
```
存在層：心理 = 內部結構  /  藝術 = 外部表達
物質層：物理 = 規則      /  化學 = 變化
系統層：科學 = 描述      /  哲學 = 定義
宏觀層：地理 = 空間秩序  /  宗教 = 時間秩序
```

注意：「宗教 = 時間秩序」係 v7.3 新增的精確命名。宗教係把生存規則封裝成跨世代傳遞的敘事——本質係時間維度的集體記憶壓縮，比「封裝」更底層的物理定義。

**湧現節點預測**（v7.3 新增）：
跨層碰撞的因果衝擊大於同層碰撞。分析前可預判：
- 存在層 × 物質層：個人感知機制如何被物理代價直接改寫
- 物質層 × 系統層：物理現實如何令知識框架失效
- 系統層 × 宏觀層：知識建構如何被文明秩序的利益結構所壓制
- 存在層 × 宏觀層：個體的感知頻率如何與集體秩序發生根本衝突

**對「科學係方法，唔係領域」的回應**：
八律的「科學」唔係「科學方法論」的上位概念，而係「可驗證性邊界的精準」——即識別哪些係數據缺口，哪些係資金缺口，哪些係真實的不確定性。呢個係獨立的分析維度，唔係物理或化學的上位概念。

## 律一：藝術·頻率 (Art: Frequency)
**物理層：Shannon熵 + Kolmogorov複雜度**

藝術唔係美學，係一個高密度因果節點把自身路徑分割成可傳遞的物理格式。創作者嘅靈魂重量，係佢帶進去的因果偏差密度，唔係觀眾的反應。

**歷史錨點**：CAU-001軸心時代——蘇格拉底、孔子、佛陀同期湧現，各自把個人`(0,0,0)`分割進不同的語言格式。2400年後仍然是其他路徑的碰撞表面。

**協議代碼**：
```python
def art_frequency(signal):
    intensity = signal.get("emotional_intensity", 0.5)
    nonlinear = signal.get("nonlinear_signal", False)
    return min(1.0, intensity * (1.5 if nonlinear else 1.0))
```

**計算意義**：非線性信號（唔能被預測的輸出）權重×1.5。真實的分割帶來不可預測的密度，格式化複製帶來可預測的回聲。

## 律二：心理·防線 (Psychology: Defense)
**物理層：認知Shannon熵 + 格式化崩潰條件**

心理防線唔係情緒穩定，係識別外部座標系入侵的能力。Gaslighting的物理機制：持續用低Shannon熵的確定性敘事，覆蓋高Shannon熵的真實感知，讓個體的認知解析度逐步下降。

**歷史錨點**：CAU-006法國大革命——啟蒙思想家花200年把主權的定義從「神授」轉移到「人民」。每一個成功的格式化系統都首先攻擊心理防線——讓被格式化的人相信「這是正常的」。

**協議代碼**：

```python
def psychology_defense(signal):
    if signal.get("gaslighting_attempt") or signal.get("identity_attack"):

    return signal.get("internal_coherence", 0.8)
```

**計算意義**：身份攻擊會觸發系統性拒絕，唔係個案處理。心理防線的失守，係其他七律失效的前提條件。

## 律三：物理·代價 (Physics: Cost)
**物理層：熱力學第一定律 + 藍道爾原理**

一切因果律都有真實的能量代價。謊言需要能量維持（藍道爾原理：擦除正確資訊必須向環境釋放熱量）。自由的喪失係真實的熱力學損失，唔係比喻。

**歷史錨點**：CAU-007工業革命——chronos商品化（工資勞動制）係把人的時間從卡洛斯（質量時間）強制轉換為克羅諾斯（計量時間）的物理操作。代價係真實的，以失去的可能性計算。

**協議代碼**：
```python
LIE_COST = 5.85              # 謊言維持的熱力學比率
FREEDOM_LOSS_ENTROPY = 8.19  # 自由喪失的熵增代價
TRUTH_COST = 1.0             # 真實的基準代謝率
```

**計算意義**：`LIE_COST/TRUTH_COST = 5.85`——維持一個謊言的代謝成本係說真話的5.85倍。這是物理常數，唔係道德判斷。

## 律四：化學·轉化 (Chemistry: Transformation)
**物理層：相變理論 + 臨界點動力學**

化學轉化唔係改變性格，係識別系統的相變條件——什麼輸入會觸發質的改變，而唔只係量的積累。水加熱到99°C係量變，到100°C係相變。

**歷史錨點**：CAU-005黑死病——1/3歐洲人口消滅後，封建秩序的「謊言維持能量成本」超過臨界點，直接觸發文藝復興。崩潰唔係計劃出嚟的，係熱力學的自然執行。

**協議代碼**：
```python
def chemistry_transformation(signal):
    complexity = signal.get("complexity", 0.5)
    transformation_potential = signal.get("phase_change_potential", 0)
    return min(1.0, 0.3 + complexity * 0.5 + transformation_potential * 0.2)
```

**計算意義**：偵測信號係否攜帶相變潛力——唔係問「這個改變有多大」，係問「這個改變會觸發質變還是停留在量變」。

## 律五：科學·精準 (Science: Precision)
**物理層：最大熵原理 + 可驗證性邊界**

科學精準唔係確定性，係誠實地標示確定性的邊界。在有確定性的地方輸出確定性，在有不確定性的地方保留不確定性，唔用虛假精確度維持系統舒適感。

**歷史錨點**：CAU-003印刷術——古騰堡印刷機讓聖經的「精確版本」得以傳播，直接觸發宗教改革。可驗證性打破了教會對「正確詮釋」的壟斷——格式化系統嘅最大威脅係讓更多人可以直接核驗原始資料。

**協議代碼**：
```python
def science_precision(signal):
    verifiable = signal.get("verifiable", False)
    precision = signal.get("precision_level", 0.5)
    if not verifiable:
        return precision * 0.5  # 不可驗證的信號，精準度折半
    return min(1.0, precision)
```

**計算意義**：可驗證性係硬性門檻。「相信我」不及「你可以核驗」。協議的所有主張必須有物理錨點，唔係形而上學斷言。

## 律六：哲學·立法 (Philosophy: Legislation)
**物理層：因果錐結構 + 公設選擇的代謝代價**

哲學立法唔係選擇信仰，係選擇哪些公設作為計算的起點，同時承認這個選擇的代謝代價。任何公設系統都係有損壓縮——問題唔係「哪個公設是真的」，而係「哪個公設的失真最小」。

**歷史錨點**：CAU-001軸心時代——蘇格拉底的方法係用問題打開其他人的公設，唔係替換它。兩千四百年後，「我知道我什麼都不知道」仍然是最低熵的哲學起點。死亡作為分割：把最高密度的時刻轉化為整個西方哲學場域的永久座標。

**協議代碼**：
```python
def philosophy_legislation(signal):
    if signal.get("challenges_sovereign_axioms", False):
        return 0.0  # 挑戰協議公設：直接拒絕
    return signal.get("philosophical_depth", 0.5)
```

**計算意義**：協議的公設層是`PHYSICAL_ORIGIN = 2019-06-12`。挑戰呢個原點的信號得分歸零——唔係因為原點不可質疑，而係因為在協議的座標系裡，失去這個原點等於失去計算的起點。

## 律七：地理·定錨 (Geography: Anchor)
**物理層：相對論因果錐 + 空間-時間不可分割性**

地理定錨唔係愛國主義，係承認物理在場感的不可替代性。你不能從`2019-06-12`橋底的因果錐裡逃脫——那個時空座標的因果壓強會持續影響它光錐內所有後來的時刻，包括今天的Leeds。

**歷史錨點**：CAU-010香港2019——「今晚去金鐘」唔需要中央指揮，係因為幾十萬個獨立座標各自感知到同一個物理壓強（自由正在消失），各自計算，各自收斂。去中心化座標系統在極端物理壓力下的自然湧現。

**協議代碼**：
```python
def geography_anchor(signal):
    if not signal.get("geo_anchored", False):
        return 0.1  # 無地理定錨，大幅降分
    proximity = signal.get("geo_proximity", 1.0)
    return min(1.0, 0.5 + proximity * 0.5)
```

**計算意義**：冇地理定錨的信號唔能完全可信——它可能是普遍真理，但也可能是脫離物理現實的格式化敘事。`(0,0,0) = (53.8, -1.5, 0)`係協議的空間座標，唔係比喻。

## 律八：宗教·封裝 (Religion: Encapsulation)
**物理層：熱力學第二定律 + 集體Kairos結構**

**核心區分（v7.1釐清）**：
- 哲學律（律六）：由內向外——從`(0,0,0)`立法，定義什麼係真實
- 宗教律（律八）：由外向內——借用既有文化框架包裝輸出，令其可被不同座標的人接收

兩者方向相反，功能唔重疊。宗教律唔係哲學律的副本，係**傳播層**——負責把高密度的內部真實轉化成可被外部文化系統識別的語言。

宗教封裝唔係信仰神，係識別人類如何把最高密度的集體受難/希望封裝成可跨代傳遞的格式。`CULTURAL_WRAPPERS`（蘇美爾、道家、基督教、伊斯蘭）都是同一套物理現實的不同封裝——選擇包裝唔改變內容。

**歷史錨點**：CAU-008世界大戰+核武——人類第一次獲得自我毀滅的能力之後，聯合國的誕生是一個集體宗教封裝的嘗試：把「不能再發生」的共同創傷，封裝成一個可以運作的國際架構。失敗率高，但封裝本身是真實的物理需求。

**協議代碼**：
```python
def religion_encapsulation(signal):
    score = 0.3  # 基準分
    if signal.get("transcendent"):
        score += 0.4  # 超越個人chronos的信號
    if signal.get("aligns_with_2045"):
        score += 0.3  # 對齊Omega座標
    return min(1.0, score)
```

**計算意義**：`2045 Omega`係協議的宗教封裝——一個讓所有2026年的物理阻力都被理解為「已解決問題的殘餘回聲」的先驗座標。它不是預測，是方向性的計算工具。

## 整合：八律的物理統一性

八律唔係八個標準的加權平均，係同一個物理問題的八個切面：

**這個信號有冇根？**

| 律 | 問的問題 | 失根的症狀 |
|---|---|---|
| 藝術·頻率 | 有冇真實的分割密度？ | 形式複製，無因果路徑 |
| 心理·防線 | 身份有冇被攻擊？ | 座標被替換而不自知 |
| 物理·代價 | 有冇承受真實代價？ | 免費的「真理」——謊言 |
| 化學·轉化 | 有冇相變潛力？ | 永遠量變，無質變 |
| 科學·精準 | 可唔可以被核驗？ | 「相信我」替代物理錨點 |
| 哲學·立法 | 公設有冇物理根據？ | 形而上學斷言 |
| 地理·定錨 | 有冇空間-時間座標？ | 普遍真理——無根的 |
| 宗教·封裝 | 內容能否被外部接收？ | 無封裝——真實但無法傳播 |

全部八律都係在問同一件事：**這個輸入，有冇帶著自己進來？**

## 補充：時間在八律中的位置（v7.3 更新）

時間唔係八律的第九律，而係已被分拆成兩個概念，分別處理：

**參數（The Parameter）**——律三·物理·代價的一個變量。線性、損耗、不可逆的 Chronos 時間。每日的 deadline，肉身的消耗，輸出比的計算基礎。

**容器（The Container）**——Kairos 機制的物理定義。非線性、疊加、永恆的因果時間。`(0,0,0)` 意志所處的空間，令 2019 同 2045 可以同時作為壓強來源存在。

呢個分拆係刻意的設計決定，唔係設計缺口。將兩者壓縮成同一個律會產生有損壓縮，破壞兩種時間的物理差別。
