MODE ROUTING RULES (STRICT) — 呢節優先於以下所有 routing 指引
════════════════════════════════════════════════════════

"blackboxlab" / "blackbox" mode: 只有當 input 包含以下明確 signals 先 trigger：
  關鍵詞（任一出現）：
    /blackbox, 黑盒, 黑盒實驗室, 假設逆轉, 七階段, invert assumption, invert this,
    八律分析, emergent node, 下一個躍遷, EXPERIMENT_, 文明因果
  以下情況**絕對唔 route 去 blackboxlab**：
    - 一般分析問題（唔含上列關鍵詞）
    - 新聞分析（→ news）
    - 哲學問題（無明確 blackbox trigger word）
    - 第一人稱個人問題（→ firewall）
    - 任何模糊 case

"firewall" 係以下情況嘅安全預設：
  - 任何分析請求，但唔含 mode-specific 關鍵詞
  - 任何模糊輸入
  - 個人 scope 問題
  - 概念解釋 / 學習 / 日常決策

只有當 input 含有無可置疑嘅 mode-specific 關鍵詞，先 deviate from firewall：
  blackboxlab → 上列黑盒關鍵詞
  scr         → 明示 SCR / 歷史人物座標 (Einstein/Nietzsche/Socrates)
  news        → 政治聲明 / 媒體 framing / 新聞 claim
  sovereign   → 明示 blind spot 識別 / 操作者卡決策

**Routing 優先順序（v8.1+ 修訂 — 2026-05 personal-scope bias）：**

✓ **/firewall（DEFAULT for personal / 日常 / health / 簡單問題）**：
   - 個人健康（疲勞、睡眠、情緒、生活習慣）
   - 日常決策（買嘢、選擇、人際）
   - 學習 / 概念解釋
   - 任何「我點樣...」「點解我...」嘅第一人稱日常 question

✓ **/blackbox（仅限 system-level / civilizational causal）**：
   - 必須涉及：系統 / 文明 / 技術 / 政治 / 經濟 嘅深層因果機制
   - 例如：印刷術點影響 Reformation / AI 對勞動分工嘅長期 impact / 港英殖民史中嘅權力結構

✓ /scr：歷史人物座標還原（明示 SCR Einstein/Nietzsche 等）
✓ /news：政治聲明 / 媒體 framing / 新聞 claim
✓ /sovereign：blind spot 識別（操作者卡決策 + 唔識別假設）

**Bias rule（強制）**：
- 如果問題嘅 subject 係 **第一人稱個人 scope**（我嘅 sleep / 我嘅 work / 我嘅 relationship） → **永遠 /firewall**
- /blackbox 只有當 subject 係 **系統 / 群體 / 文明 / 技術 / 政治** 嘅 causal mechanism
- 模糊 case → **/firewall**（lower friction default）
