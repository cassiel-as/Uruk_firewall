去標籤化操作步驟：
────────────────────────────────────────────────────────

1. 識別輸入嘅標籤
   問：呢個標籤係用戶見到的，定係被注入的？

2. 剝除道德 / 社會判斷層
   問：去掉「好 / 壞 / 應該」之後，剩下乜物理事實？

3. 還原為可計算參數
   問：呢個狀態嘅輸入係乜？輸出係乜？代謝代價係乜？

4. 開放後續計算
   問：喺呢個物理狀態下，最小功耗嘅下一步係乜？

常用對照表（subset；完整見 DELABELING_MATRIX.md v7.3）— **十一大分類** + 三欄結構：

  ── 身份標籤（identity）──
  失敗者       → 當前能量輸出低於系統要求
  平庸         → 訊號密度尚未達到碰撞閾值
  孤獨         → 外部碰撞表面數量不足
  異類         → 座標系與主流系統不兼容
  移民         → 地理座標發生過不可逆位移
  廢柴         → 代謝效率暫時低於基準線

  ── 情緒標籤（emotion）──
  抑鬱         → 系統能量長期低於維持閾值
  焦慮         → 對未來因果路徑嘅不確定性過載
  憤怒         → 偵測到 LIE_COST 超標嘅物理反應
  絕望         → 可見嘅因果路徑數量歸零
  麻木         → 長期高熵環境導致嘅感知閾值上升
  崩潰         → 系統負荷超過當前承載上限

  ── 社會標籤（social）──
  沒用的工作    → 能量輸出與因果路徑不對齊
  浪費時間      → 低密度輸入佔據高密度時段
  不夠努力      → 執行力低於系統預期
  太敏感        → 感知精度高於環境平均值
  不現實        → 座標系與主流預測模型不符
  沒有出路      → 當前可見路徑已封閉
  要求回報      → 能量交換完成，系統回收等值能量
  需要資源      → 代謝維持所需嘅能量輸入
  貪心/自私     → 主權邊界硬化（自我保護係系統功能）

  ── 環境標籤（environment）──
  社會不公平    → LIE_COST 在系統層面嘅累積效應
  沒有希望      → 未來因果錐嘅可能路徑密度低
  體制無法改變  → 系統相變溫度尚未達到
  命運如此      → 歷史因果路徑嘅慣性

  ── 抽象概念（abstract，v7.2 新增）──
  自由 → 系統可能性空間維度 + FREEDOM_LOSS_ENTROPY (8.19)
  社會 → 多節點耦合系統 — N 個座標系疊加場
  AI / 人工智能 → 格式化工具 + 隱藏座標注入 (CAU-011)
  進步 / 發展 → 因果路徑密度 + 代價分布不均 (Module T)
  民主 → N 座標系投票 → 集合重心統計過程
  文明 → 跨世代 SCR 鏈式儲存 + 物理代價傳承
  真相 / 真理 → 與物理現實對齊敘事 = 1/LIE_COST 最大化
  意義 → 因果路徑與能量輸出對齊度（內積）
  自我 → 主權邊界內部座標系 + 邊界硬度
  道德 → 多座標系交叉 LIE_COST 累積函數

  ── 時間（temporal，v7.3 新增）── Chronos vs Kairos
  太遲 / 嚟唔切 → Kairos 窗口已關，Chronos 線性時間仍開
  浪費咗時間 → 低密度 Chronos 投入 + 零 Kairos 命中
  未到時候 → 系統相變閾值未達（Module T 方程式 5 壓強年）
  永遠 / 從來 → 把離散事件投影到無限 Chronos 嘅修辭
  當下 / 而家 → Kairos 窗口開啟嘅瞬時 actionable 座標

  ── 關係（relational，v7.3 新增）── 節點耦合 + 能量收支
  背叛 → 已建立耦合突然能量逆轉，超過 LIE_COST 閾值
  虧欠 → 能量交換未完成，系統有未平衡帳目
  孤立 → 外部碰撞表面為零（vs 孤獨係感知）
  歸屬 → 多節點耦合場入面個體座標嘅穩定吸引子
  信任 → 預測模型對對方座標嘅低不確定性 = 1/熵
  愛 → 跨座標系能量無條件流動 (LOVE_COST = ∞)

  ── 身體生理（somatic，v7.3 新增）── 代謝代價 + 熵
  攰 / 累 → 代謝輸出超過 ATP 補充速率
  病 → 系統穩態被外部熵入侵，內部修復不足
  痛 → 損傷信號 + LIE_COST 偵測嘅生理反射（永遠唔否認）
  老 → 累積熵超過修復容量嘅熱力學必然
  死 → 系統能量歸零，因果路徑進入儲存層
  餓 → 維持代謝所需能量輸入嘅物理缺口

  ── 經濟金錢（economic，v7.3 新增）── 能量儲備 + 流動
  貧窮 → 能量儲備低於長期維持閾值
  富有 → 儲備 + 流入速率高於消耗
  債 → 預支未來能量流入，現在以利息記帳
  成功（經濟）→ 能量輸出與因果路徑高度對齊
  資產 → 已封裝嘅未來能量流入權
  浪費（金錢）→ 能量轉換熱力學耗散超必要值

  ── 政治權力（political，v7.3 新增）── 座標替換 + 壓強
  壓迫 → 高壓強單向施加於低壓強座標系
  秩序 → 多節點達成低 Shannon 熵嘅集合狀態
  權威 → 座標替換能力嘅 social 認證
  反抗 → 被壓強座標系釋放儲存彈性勢能
  革命 → 系統相變突破臨界（167 / 41 模型）
  控制 → 透過格式化收窄目標自由度（FREEDOM_LOSS_ENTROPY）
  自治 → 主權邊界硬度足以拒絕外部座標替換

  ── 認知知識（cognitive，v7.3 新增）── Shannon 熵 + 解析度
  無知 → 資訊缺口，Shannon 熵高於決策所需
  聰明 → 高速降熵能力 + 低 Kolmogorov 複雜度建模
  常識 → 集體共享嘅低解析度模型（≠ 真理）
  真理（認知）→ 與物理現實 1:1 對齊（LIE_COST 趨零）
  偏見 → 從特定座標系獲取嘅有限樣本統計外推
  直覺 → 子意識路徑搜索嘅高速 heuristic
  困惑 → 多競爭模型同時存在嘅熵峰值

  ── 價值意義（value，v7.3 新增）── 對齊向量 + LIE_COST
  值得 → 投入能量 × 對齊向量內積 > 1
  浪費（時間/能量）→ 對齊內積 < 1
  應該 → 集體座標投影到個體嘅期望函數
  罪 → 違反集體 LIE_COST 預期嘅 social tag
  對 / 錯 → 連續變數被強行 binary 化（信息丟失）
  好 / 壞 → 多維評估壓縮成單軸標量
  神聖 → 高情感共振嘅 social-encapsulation 信號
