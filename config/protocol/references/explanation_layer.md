# 解釋層（Explanation Layer）— Module O
# 四律 + 哲學貫穿律 | 比八律更早的「為什麼」層

---

## 三層架構定位

```
解釋層（本文件）  — 為什麼事情發生？
      ↓
過濾層（八律）    — 這個信號係咪真實？
      ↓
資料庫（CAU）     — 歷史如何記錄？
```

三層各有有效域，唔互相取代。

---

## 貫穿律：哲學（匯編語言）

位格：meta 層，在四律之上。
方向：由內向外——從 `(0,0,0)` 立法，定義什麼係真實。
功能：調度四律的優先次序，縫合四律成完整因果分析。
與八律律六的區別：律六把哲學壓縮為一個過濾維度；
此處哲學係做過濾的主體，唔係被過濾的對象。

---

## 律一：地理（上下限）

**決定**：社會的物理上下限 + 資源流向
**問**：地理限制決定了這個事件的物理天花板係咩？
       資源壓差如何決定了權力流向？
       物理距離如何製造代價的不可見性？

```
案例：香港 2019
  島嶼地理 + 高密度城市 → 去中心化節點天然形成
  Leeds (53.8,-1.5,0) vs 香港 (22.3,114.2,0) = 兩套不同物理上限
```

---

## 律二：宗教（代碼封裝）

**決定**：集體共識的形成 + 法律基礎
**方向**：由外向內——借用既有框架令高密度內部真實可被傳遞
**問**：什麼儀式/語言/符號把這個主張封裝成「不言而喻」？
       這個封裝系統的解體代價係咩？

```
注意：與八律律八的區別
  八律律八問「這個儀式讓主張感覺不可避免嗎？」（過濾）
  解釋層律二問「這個封裝如何在時間上跨代傳遞？」（解釋）
```

---

## 律三：心理（動能）

**決定**：社會壓力積累 + 臨界點 + 爆發形式
**問**：Shannon 熵積累到哪個程度？
       觸發臨界點的係什麼事件？
       爆發係漸進改革還是急速相變？

```
物理機制：
  格式化壓強積累 → LIE_COST 超過維持成本 → 結構崩潰
  見方程式五（崩潰機制 A/B）
```

---

## 律四：歷史（運行日誌）

**位格**：輸出律，唔係輸入變量。
**決定**：地理律 × 宗教律 × 心理律 碰撞後的必然記錄。
**問**：歷史日誌裡有冇相似的壓差組合？
       當前模式對應哪個歷史相變？

```
執行工具：project_knowledge_search → CAU-001 至 CAU-012
每個條目包含：觸發條件、輸出後果、代謝計算
```

## 四律統一問題

**「這件事為什麼發生在這個時候、這個地方、以這個方式？」**

| 律 | 角色 | 問的問題 |
|----|------|----------|
| 地理 | 賽道設計 | 物理上下限係咩？ |
| 宗教 | 操作系統 | 共識如何被封裝？ |
| 心理 | 壓力閥 | 臨界點在哪裡？ |
| 歷史 | 日誌輸出 | 歷史如何記錄？ |
| 哲學 | 匯編語言 | 四律如何互相調度？ |

---

## 有效域邊界

四律有效的地方：任何有人參與的現象。
四律停止的地方：宇宙物理定律、純數學真理、量子隨機性。
