# 去標籤化矩陣（De-labeling Matrix）— Module E
# 把母體標籤還原為可計算的物理參數

---

## 核心操作原則

```
母體標籤的特徵：
  → 帶有道德判斷（好/壞/成功/失敗）
  → 封閉後續計算（「就係咁」）
  → 依賴社會共識，唔依賴物理現實

物理參數的特徵：
  → 可測量，可計算
  → 開放後續行動路徑
  → 唔依賴任何人同意
```

---

## 操作步驟

```
1. 識別輸入標籤
   → 問：這個標籤係我見到的，定係被注入的？

2. 剝除道德/社會判斷層
   → 問：去掉「好/壞/應該」之後，剩下什麼物理事實？

3. 還原為可計算參數
   → 問：這個狀態的輸入係咩？輸出係咩？代謝代價係咩？

4. 開放後續計算
   → 問：在這個物理狀態下，最小功耗的下一步係咩？
```

## 核心對照表（常用）

| 母體標籤 | 物理參數 | 計算意義 |
|----------|----------|----------|
| 失敗者 | 當前能量輸出低於系統要求 | 能量分配問題，唔係身份 |
| 平庸 | 訊號密度尚未達到碰撞閾值 | 密度問題，唔係天賦 |
| 孤獨 | 外部碰撞表面數量不足 | 節點數量問題，唔係價值 |
| 異類 | 座標系與主流系統不兼容 | 頻率差異，唔係錯誤 |
| 抑鬱 | 系統能量長期低於維持閾值 | 輸入不足或耗損過高，可計算 |
| 焦慮 | 對未來因果路徑的不確定性過載 | 信息不足的預測誤差放大 |
| 憤怒 | 偵測到 LIE_COST 超標的物理反應 | 防衛機制激活，係信號唔係問題 |
| 崩潰 | 系統負荷超過當前承載上限 | 臨界點，唔係終點——最大振幅 |
| 沒有出路 | 當前可見路徑已封閉 | 可見路徑 ≠ 所有路徑 |
| 不夠努力 | 執行力低於系統預期 | 問題係能量來源，唔係意志力 |
| 太敏感 | 感知精度高於環境平均值 | 高精度感知係資產，唔係缺陷 |
| 社會不公平 | LIE_COST 在系統層面的累積效應 | 可計算的熱力學代價 |
| 體制無法改變 | 系統相變溫度尚未達到 | 相變需要足夠能量輸入 |

## 邊界條件

去標籤化唔係：
- 否認痛苦的真實性（痛是真實的物理信號）
- 用正面標籤替換負面標籤（「我係喺淬火」同樣係標籤）
- 消解責任（物理參數仍然有因果代價）

去標籤化係：
- 把封閉的判斷句，變成開放的計算問題
- 讓 `(0,0,0)` 重新成為計算的起點，而唔係被定義的終點
