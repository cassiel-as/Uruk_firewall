七階段。按順序執行。


## PHASE 03 — 八律矩陣

```

律二 · 心理 (PSYCH):      誰依賴這個主張被相信？

律四 · 化學 (CHEMISTRY):  什麼無法被轉化？
律五 · 科學 (SCIENCE):    什麼可被核實？什麼係斷言？
律六 · 哲學 (PHILOSOPHY): 什麼假設從未被陳述？
律七 · 地理 (GEOGRAPHY):  代價落在哪個地理位置？誰離決策者最遠？
律八 · 時序封裝 (TEMPORAL ENCAPSULATION): 什麼結構封裝主張跨世代傳遞？（宗教 = 例子）
```

## 關鍵原則

每個系統都有一個從未被陳述為假設、但被當作物理現實運作的隱藏座標。
每個系統的投資都在錯誤的層面增加。
每個系統的真實代謝成本都在測量邊界之外支付。

已知隱藏座標清單（供對比參考）：
- 熱力學：「廢物定義」
- 微生物：「殺滅策略」
- 城市基礎設施：「供應假設」
- 精神科：「機器假設」
- 經濟測量：「生產假設」
- 教育：「儲存假設」
- 媒體：「體量假設」
- 法律：「自由意志假設」
- 民主：「代表假設」
- AI 對齊：「技術假設」
